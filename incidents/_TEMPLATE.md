# [Title: what broke, in plain words]

**Impact:** Who or what was affected, and for how long.
**Affected:** The systems involved.

## What happened
The symptom, and how it showed up. Better if a monitor caught it than if
someone had to tell you.

## Digging in
How you narrowed it down. Worth showing the wrong turns and the things you
ruled out, not just the answer.

## Root cause
The actual reason, stated plainly.

## Fix
What you changed to resolve it.

## Prevention
What's in place now so it doesn't come back. Monitoring, a config change in
version control, an architecture change, or a note that the real underlying
problem is still on the list.
